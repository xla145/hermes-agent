# 智能派单详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 智能派单 |
| 页面编号 | T013 |
| 所属模块 | 智能调度 |
| 页面类型 | 派单页 |
| 路由路径 | /dispatch/auto |
| 访问角色 | 调度员 |
| 关联功能点 | F018 |
| 关联业务场景 | 场景2 |

## 2. 页面结构

| 区域 | 名称 | 说明 |
| :--- | :--- | :--- |
| A区 | 订单信息 | 待派单订单详情 |
| B区 | 推荐方案 | 系统推荐的派单方案 |
| C区 | 确认操作 | 确认/取消派单 |

## 3. 推荐方案内容

- 推荐车辆：车牌号、车型、当前位置、预计到达时间
- 推荐司机：姓名、联系方式、当前任务
- 匹配度：距离匹配、载重匹配、时效匹配

## 4. 操作

| 操作 | 说明 |
| :--- | :--- |
| 确认派单 | 确认推荐方案并执行派单 |
| 手动调整 | 跳转手动派单页面 |
| 取消 | 返回调度看板 |

## 5. 原型生成说明

- 展示推荐的派单方案，包含车辆和司机信息
- 显示匹配度指标
- 支持确认和手动调整操作
