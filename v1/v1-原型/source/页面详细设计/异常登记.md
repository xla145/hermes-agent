# 异常登记详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 异常登记 |
| 页面编号 | T020 |
| 所属模块 | 异常处理 |
| 页面类型 | 新增页 |
| 路由路径 | /exceptions/create |
| 访问角色 | 客服、司机 |
| 关联功能点 | F028 |
| 关联业务场景 | 场景4 |

## 2. 页面结构

| 区域 | 名称 | 说明 |
| :--- | :--- | :--- |
| A区 | 关联订单 | 选择异常关联的订单 |
| B区 | 异常信息 | 异常类型、描述、附件 |
| C区 | 提交按钮 | 提交、取消 |

## 3. 表单字段

| 字段 | 说明 |
| :--- | :--- |
| orderId | 关联订单（必选） |
| exceptionType | 异常类型（必选） |
| description | 异常描述（必填） |
| attachment | 附件上传（可选） |
