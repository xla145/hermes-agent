# 新建订单详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 新建订单 |
| 页面编号 | T004 |
| 所属模块 | 订单管理 |
| 页面类型 | 新增页 |
| 路由路径 | /orders/create |
| 访问角色 | 客服 |
| 关联功能点 | F006 |
| 关联业务场景 | 场景1 |
| 关联数据对象 | 订单、客户 |

## 2. 页面目标与使用场景

- **页面目标**：创建新的物流订单，填写发货信息、货物信息、时效要求
- **使用场景**：客服录入客户发货需求
- **触发入口**：订单列表点击"新建订单"按钮
- **输出结果**：创建新订单并跳转到订单列表

## 3. 权限与访问控制

| 角色 | 可执行操作 |
| :--- | :--- |
| 客服 | 新建订单 |
| 其他角色 | 不可见新建按钮 |

## 4. 页面结构与区域划分

| 区域 | 名称 | 包含组件 |
| :--- | :--- | :--- |
| A区 | 客户信息 | 客户选择器 |
| B区 | 发货信息 | 发货地输入、联系人、电话 |
| C区 | 收货信息 | 收货地输入、联系人、电话 |
| D区 | 货物信息 | 货物名称、数量、重量、体积 |
| E区 | 时效要求 | 时效类型、截止时间 |
| F区 | 提交按钮 | 提交、取消 |

## 5. 表单字段设计

| 字段名称 | 字段类型 | 是否必填 | 校验规则 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| customerId | Select | 是 | 选择已有客户 | - | 客户选择 |
| fromCity | Input | 是 | 必填 | - | 发货城市 |
| fromAddress | Input | 是 | 必填 | - | 详细地址 |
| fromContact | Input | 是 | 手机号格式 | - | 发货联系人 |
| fromPhone | Input | 是 | 手机号格式 | - | 联系电话 |
| toCity | Input | 是 | 必填 | - | 目的城市 |
| toAddress | Input | 是 | 必填 | - | 详细地址 |
| toContact | Input | 是 | 手机号格式 | - | 收货联系人 |
| toPhone | Input | 是 | 手机号格式 | - | 联系电话 |
| goodsName | Input | 是 | 必填 | - | 货物名称 |
| goodsQuantity | Number | 是 | >0 | - | 货物数量 |
| goodsWeight | Number | 是 | >0 | - | 重量(kg) |
| goodsVolume | Number | 是 | >0 | - | 体积(m³) |
| timeType | Select | 否 | - | 普通 | 时效类型 |
| expireTime | DateTime | 否 | >当前时间 | - | 要求送达时间 |
| remark | Textarea | 否 | - | - | 备注 |

## 6. 操作清单

| 操作名称 | 操作角色 | 前置条件 | 反馈提示 |
| :--- | :--- | :--- | :--- |
| 提交 | 客服 | 表单验证通过 | "订单创建成功" |
| 取消 | 客服 | 无 | 返回订单列表 |
| 重置 | 客服 | 无 | 清空表单 |

## 7. 交互逻辑

- 选择客户后自动填充联系人信息
- 提交成功后自动跳转到订单列表
- 表单验证失败显示对应错误提示

## 8. 原型生成说明

- 页面布局：表单在左侧，右侧显示填写提示
- 关键交互：表单验证、提交按钮
- 模拟数据：预填部分可选数据
