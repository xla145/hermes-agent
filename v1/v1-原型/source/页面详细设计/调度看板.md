# 调度看板详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 调度看板 |
| 页面编号 | T012 |
| 所属模块 | 智能调度 |
| 页面类型 | 看板页 |
| 路由路径 | /dispatch |
| 访问角色 | 调度员 |
| 关联功能点 | F017 |
| 关联业务场景 | 场景2 |

## 2. 页面目标与使用场景

- **页面目标**：展示待派单订单、可用车辆，提供快速派单入口
- **使用场景**：调度员日常派单工作
- **触发入口**：导航菜单"智能调度 → 调度看板"

## 3. 页面结构与区域划分

| 区域 | 名称 | 说明 |
| :--- | :--- | :--- |
| A区 | 待派单订单 | 待派单订单列表 |
| B区 | 可用车辆 | 空闲车辆列表 |
| C区 | 派单操作 | 智能派单/手动派单按钮 |

## 4. 操作清单

| 操作 | 说明 |
| :--- | :--- |
| 智能派单 | 选择订单后点击智能派单 |
| 手动派单 | 选择订单后点击手动派单 |
| 查看详情 | 点击订单查看详情 |

## 5. 数据字段

- 待派单订单：订单号、客户、货物、发往、重量、创建时间
- 可用车辆：车牌号、车型、载重、当前位置、司机

## 6. 原型生成说明

- 布局：左侧待派单列表，右侧可用车辆，顶部派单按钮
- 交互：选择订单→选择车辆→确认派单
