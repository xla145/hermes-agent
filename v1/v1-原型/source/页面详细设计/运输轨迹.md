# 运输轨迹详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 运输轨迹 |
| 页面编号 | T016 |
| 所属模块 | 运输轨迹 |
| 页面类型 | 地图页 |
| 路由路径 | /tracking |
| 访问角色 | 调度员、客服、物流经理 |
| 关联功能点 | F022、F024 |
| 关联业务场景 | 场景3 |

## 2. 页面结构

| 区域 | 名称 | 说明 |
| :--- | :--- | :--- |
| A区 | 地图展示 | 车辆实时位置显示 |
| B区 | 车辆列表 | 在线车辆列表 |
| C区 | 里程碑 | 运输节点时间轴 |

## 3. 功能说明

- 实时追踪：在地图上显示车辆当前位置
- 里程碑记录：展示运输过程中的节点时间
- 轨迹回放：可跳转到历史轨迹回放

## 4. 原型生成说明

- 布局：左侧地图，右侧车辆列表，底部里程碑
- 模拟数据：3-5辆运输中车辆的位置信息
