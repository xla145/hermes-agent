# 手动派单详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 手动派单 |
| 页面编号 | T014 |
| 所属模块 | 智能调度 |
| 页面类型 | 派单页 |
| 路由路径 | /dispatch/manual |
| 访问角色 | 调度员 |
| 关联功能点 | F019 |
| 关联业务场景 | 场景2 |

## 2. 页面结构

| 区域 | 名称 | 说明 |
| :--- | :--- | :--- |
| A区 | 订单信息 | 待派单订单详情 |
| B区 | 车辆选择 | 可用车辆列表（可搜索） |
| C区 | 司机选择 | 空闲司机列表（可搜索） |
| D区 | 确认操作 | 确认派单按钮 |

## 3. 操作流程

1. 查看订单信息
2. 从车辆列表选择车辆
3. 从司机列表选择司机
4. 点击确认派单
5. 派单成功后跳转到调度看板

## 4. 原型生成说明

- 布局：左侧订单信息，中间车辆和司机选择，底部确认按钮
- 交互：选择车辆和司机后确认派单
