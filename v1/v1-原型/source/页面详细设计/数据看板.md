# 数据看板详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 数据看板 |
| 页面编号 | T024 |
| 所属模块 | 数据看板 |
| 页面类型 | 看板页 |
| 路由路径 | /dashboard |
| 访问角色 | 物流经理、财务 |
| 关联功能点 | F035-F040 |
| 关联业务场景 | 场景5 |

## 2. 页面结构

| 区域 | 名称 | 说明 |
| :--- | :--- | :--- |
| A区 | 核心指标 | 订单量、运输量、准时率、成本 |
| B区 | 订单统计 | 订单量趋势图 |
| C区 | 车辆统计 | 车辆利用率图表 |
| D区 | 司机统计 | 司机工作量图表 |
| E区 | 财务统计 | 运费统计图表 |
| F区 | 导出功能 | 报表导出按钮 |

## 3. 统计维度

- 运营概览：当日订单量、运输中订单、准时率、车辆使用率
- 订单统计：订单量趋势、订单类型分布
- 车辆统计：车辆利用率、行驶里程
- 司机统计：工作量、准点率、异常率
- 财务统计：运费收入、成本分析

## 4. 原型生成说明

- 使用图表展示统计数据
- 支持时间维度切换
- 支持报表导出
