# 订单详情详细设计

## 1. 页面基础信息

| 字段 | 内容 |
| :--- | :--- |
| 页面名称 | 订单详情 |
| 页面编号 | T003 |
| 所属模块 | 订单管理 |
| 页面类型 | 详情页 |
| 路由路径 | /orders/:id |
| 访问角色 | 调度员、客服、仓库 |
| 关联功能点 | F005、F008 |

| 关联数据对象 | 订单、运输任务、轨迹 |

## 2. 页面目标与使用场景

- **页面目标**：展示订单全量信息，包括发货信息、承运信息、运输轨迹、签收状态
- **使用场景**：查询订单详细信息、处理订单异常、查看运输进度
- **触发入口**：订单列表点击订单号
- **输出结果**：订单详细信息展示

| :--- | :--- | :--- | :--- |

## 9. 异常、空状态和边界场景

| 场景 | 页面表现 | 处理方式 |
| :--- | :--- | :--- |
| 订单不存在 | 显示"订单不存在" | 返回列表 |
| 轨迹数据为空 | 显示"暂无轨迹信息" | 正常显示 |
| 承运信息为空 | 显示"待派单"提示 | 显示派单按钮 |

## 10. 原型生成说明

- 页面布局：左侧信息卡片组+右侧时间轴
- 关键交互：派单按钮、取消按钮、返回按钮
- 模拟数据：包含一条完整的运输中订单数据
