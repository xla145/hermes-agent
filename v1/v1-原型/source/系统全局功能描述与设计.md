## 2. 系统边界与业务闭环

### 2.1 系统边界

- **系统负责范围**：
  - 订单全生命周期管理（从订单创建到签收回单归档）
  - 车辆与司机信息管理
  - 智能调度与派单管理
  - 运输轨迹实时追踪与回放
  - 异常预警与处理
  - 签收回单电子化管理
  - 数据看板与统计分析
  - 系统基础配置与权限管理

- **不包含范围**：
  - 物流硬件设备生产与销售
  - 财务结算与支付（仅记录统计）
  - 客户自有WMS/ERP系统对接（预留接口）
  - 司机移动端App开发（Web端优先）

### 2.2 核心业务对象

| 业务对象 | 说明 | 核心属性 |
| --- | --- | :--- |
| 订单 | 物流运输需求单据 | 订单号、客户信息、货物信息、发货地、目的地、时效要求、订单状态 |
| 车辆 | 运输车辆信息 | 车牌号、车型、载重、GPS设备、车辆状态 |
| 司机 | 运输人员信息 | 姓名、联系方式、驾驶证、从业资格证、绑定车辆 |
| 运输任务 | 派单后的运输执行单 | 关联订单、关联车辆、关联司机、路线信息、任务状态 |
| 运输轨迹 | 车辆运输过程位置数据 | 经纬度、时间、速度、关联任务 |
| 异常 | 运输过程中的异常事件 | 异常类型、发生时间、处理状态、关联订单/任务 |
| 回单 | 签收回单凭证 | 签收图片、签收时间、签收状态 |
| 客户 | 发货/收货客户信息 | 客户名称、联系方式、地址、客户类型 |

### 2.3 核心业务闭环

**主业务流程闭环**：订单创建 → 调度派单 → 司机接单 → 运输执行 → 轨迹追踪 → 到达签收 → 回单归档

**辅助闭环**：
- 异常预警 → 异常登记 → 异常处理 → 处理归档
- 车辆入库 → 日常管理 → 维修/报废

## 4. 全局业务场景

### 场景1：订单全生命周期管理

- **场景目标**：实现订单从创建到完成的全流程管理
- **参与角色**：客服专员、调度员、司机、仓库管理员
- **触发条件**：客户发货需求
- **前置条件**：客户信息已维护、车辆和司机资源可用
- **核心流程**：
  1. 客服/客户新建订单，填写发货信息
  2. 调度员审核订单，进行智能派单或手动派单
  3. 司机接单，确认接单并开始运输
  4. 运输过程中实时更新轨迹状态
  5. 到达目的地，仓库/收货人确认收货
  6. 司机提交签收回单，订单完成归档
- **分支流程**：订单取消、订单修改、派单调整
- **异常流程**：派单失败、运输异常、签收异常
- **涉及功能**：订单创建、订单列表、订单详情、智能派单、手动派单、运输轨迹、签收回单
- **涉及页面**：订单列表、订单详情、新建订单、调度看板、运输轨迹、签收管理
- **涉及数据对象**：订单、客户、车辆、司机、运输任务、运输轨迹、回单
- **输出结果**：订单状态更新为已完成，回单归档
- **闭环检查**：完整
- **来源/依据**：需求结构化

### 场景2：智能调度与路线规划

- **场景目标**：高效完成派单任务，优化车辆利用率
- **参与角色**：调度员、物流经理
- **触发条件**：有待派单订单
- **前置条件**：订单已确认、车辆和司机信息完备
- **核心流程**：
  1. 调度员查看待派单订单列表
  2. 系统根据订单和车辆信息生成智能派单建议
  3. 调度员确认或调整派单方案
  4. 系统生成最优运输路线
  5. 司机收到运输任务通知
- **分支流程**：智能派单调整、手动派单、批量派单
- **异常流程**：无可用车辆、派单冲突、路线规划失败
- **涉及功能**：调度看板、智能派单、手动派单、路线规划、派单调整
- **涉及页面**：调度看板、智能派单、手动派单、路线规划
- **涉及数据对象**：订单、车辆、司机、运输任务
- **输出结果**：派单成功，生成运输任务和路线
- **闭环检查**：完整
- **来源/依据**：需求结构化

### 场景3：运输实时追踪与状态更新

- **场景目标**：实时掌握运输状态，实现过程透明化
- **参与角色**：调度员、客服专员、物流经理、客户
- **触发条件**：运输任务开始
- **前置条件**：车辆已绑定GPS设备
- **核心流程**：
  1. 司机开始运输，系统记录出发状态
  2. 车辆定位实时更新，显示在轨迹地图上
  3. 系统自动更新运输里程碑节点
  4. 异常情况自动预警提醒
  5. 到达目的地，自动提醒签收
- **分支流程**：轨迹回放、状态手动更新
- **异常流程**：GPS离线、位置漂移、轨迹中断
- **涉及功能**：实时追踪、轨迹回放、里程碑记录、状态更新
- **涉及页面**：运输轨迹、轨迹回放
- **涉及数据对象**：运输任务、运输轨迹、车辆
- **输出结果**：实时运输轨迹、状态更新记录
- **闭环检查**：完整
- **来源/依据**：需求结构化

### 场景4：异常预警与处理

- **场景目标**：快速发现异常、快速处理、降低损失
- **参与角色**：司机、调度员、客服专员、物流经理
- **触发条件**：发生异常事件（延迟、路线偏离、货物异常、车辆故障等）
- **前置条件**：异常监控规则已配置
- **核心流程**：
  1. 系统检测到异常或司机上报异常
  2. 系统生成异常预警，推送给相关人员
  3. 调度员评估异常情况
  4. 制定异常处理方案并执行
  5. 处理结果记录归档
- **分支流程**：异常升级、赔偿处理
- **异常流程**：异常处理超时、赔偿争议
- **涉及功能**：异常列表、异常详情、异常登记、异常处理、异常预警、异常统计
- **涉及页面**：异常列表、异常详情、异常登记、异常处理
- **涉及数据对象**：异常、运输任务、订单
- **输出结果**：异常处理记录、改进措施
- **闭环检查**：完整
- **来源/依据**：需求结构化

### 场景5：数据统计与决策支持

- **场景目标**：通过数据驱动业务优化
- **参与角色**：物流经理、财务专员
- **触发条件**：日常运营管理需要
- **前置条件**：数据采集完备
- **核心流程**：
  1. 物流经理登录系统
  2. 查看数据看板主页
  3. 查看各维度统计报表
  4. 分析异常数据或趋势
  5. 制定改进措施
- **分支流程**：自定义报表、报表导出
- **异常流程**：数据不完整、数据延迟
- **涉及功能**：运营概览、订单统计、车辆统计、司机统计、财务统计、报表导出
- **涉及页面**：数据看板
- **涉及数据对象**：订单、车辆、司机、财务数据
- **输出结果**：数据报表、分析结论、决策建议
- **闭环检查**：完整
- **来源/依据**：需求结构化

## 5. 全局设计规范

### 5.1 路由命名规则

| 规则项 | 规则说明 | 示例 |
| :--- | :--- | :--- |
| 路由格式 | 使用小写字母和横线分隔 | `/order-list`、`/vehicle-management` |
| 列表页 | `-list` 后缀 | `/order-list`、`/vehicle-list` |
| 详情页 | `/detail/:id` 格式 | `/order-detail/1001` |
| 新增页 | `-create` 后缀 | `/order-create` |
| 编辑页 | `-edit` 后缀 | `/order-edit/1001` |
| 弹窗/抽屉 | 使用 query 参数 | `/order-detail?id=1001&modal=edit` |

### 5.2 菜单命名规则

| 规则项 | 规则说明 | 示例 |
| :--- | :--- | :--- |
| 一级菜单 | 使用业务模块名称 | 订单管理、车辆管理、智能调度 |
| 二级菜单 | 具体功能名称 | 订单列表、全部订单、新建订单 |
| 菜单图标 | 使用通用图标库 | 参考 Ant Design Icons |

### 5.3 页面命名规则

| 规则项 | 规则说明 | 示例 |
| :--- | :--- | :--- |
| 列表页 | 业务名称 + 列表 | 订单列表、车辆列表 |
| 详情页 | 业务名称 + 详情 | 订单详情、车辆详情 |
| 表单页 | 业务名称 + 表单/新建 | 新建订单、编辑订单 |
| 统计页 | 统计维度 + 统计 | 运营概览、订单统计 |

### 5.4 页面与组件规则

| 类型 | 规则说明 | 适用范围 |
| :--- | :--- | :--- |
| 页面布局 | 左侧固定导航 + 右侧内容区，顶部可选 header | 所有业务页面 |
| 表格 | 斑马纹、列排序、可选固定表头、分页器 | 所有列表页面 |
| 表单 | 标签左对齐，校验信息在下方，提交按钮固定底部 | 所有新增/编辑页面 |
| 筛选 | 筛选项平铺或多行折叠，重置按钮置右 | 列表页面 |
| 详情 | 信息分组展示，每组标题+字段列表，重要信息突出 | 详情页面 |
| 弹窗 | 居中显示，遮罩半透明，确认/取消按钮置右 | 小型表单、轻量操作 |
| 抽屉 | 右侧滑出，标题+关闭按钮，操作按钮置底 | 详情查看、编辑操作 |
| 状态 | 标签样式：待处理-灰色、运输中-蓝色、已完成-绿色、异常-红色 | 业务状态展示 |
| 操作按钮 | 主要操作置右，次要操作使用文本按钮或图标 | 表格操作列、页面底部 |
| 异常与空状态 | 居中展示配图+提示文字+操作按钮 | 数据为空、网络错误、权限不足 |

### 5.5 权限与数据规则

| 规则类型 | 规则说明 | 适用角色/模块 |
| :--- | :--- | :--- |
| 角色权限 | 基于角色的访问控制（RBAC），超级管理员拥有全部权限 | 全部模块 |
| 菜单权限 | 角色关联菜单，未授权菜单不展示 | 全部模块 |
| 按钮权限 | 角色关联操作按钮，未授权按钮隐藏或禁用 | 业务操作 |
| 数据权限 | 部门级数据隔离，业务负责人可查看本部门数据 | 全部模块 |
| 字段权限 | 敏感字段（如联系方式）仅特定角色可见 | 客户信息、司机信息 |
| 日志留痕 | 关键操作（创建、修改、删除、审批）记录操作日志 | 全部模块 |
