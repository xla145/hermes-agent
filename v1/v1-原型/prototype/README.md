# 智能物流管理系统 - 原型说明

## 1. 原型概述

本原型是基于《智能物流管理系统》需求文档生成的多页面静态原型，用于演示和验证系统功能设计。

## 2. 使用方式

- 直接在浏览器中打开 `index.html` 即可查看系统首页
- 通过左侧导航菜单可跳转到各个功能模块页面
- 页面之间支持完整的跳转链路

## 4. 页面类型覆盖

- [x] 工作台（首页）
- [x] 列表页（订单、车辆、司机、异常、回单、用户）
- [x] 详情页（订单、车辆、异常）
- [x] 新增页（新建订单）
- [x] 看板页（调度看板、数据看板）
- [x] 地图页（运输轨迹）
- [x] 配置页（角色权限）

## 5. 主要业务链路

1. **订单管理链路**：订单列表 → 订单详情 → 新建订单
2. **调度派单链路**：调度看板 → 选择订单 → 选择车辆 → 派单
3. **运输追踪链路**：运输轨迹 → 选择车辆 → 查看里程碑
4. **异常处理链路**：异常列表 → 异常详情 → 处理异常
5. **签收回单链路**：签收回单列表 → 确认签收

## 6. 静态原型限制

- 模拟数据为静态JSON，非真实后端接口
- 地图为模拟展示，无真实地图服务
- 表单提交仅作前端验证演示
- 部分功能点击后显示Toast提示

## 7. 第二阶段输入来源

- 系统全局功能描述与设计.md
- 系统的功能点设计.md
- 页面详细设计/*.md
- 第二阶段设计检查报告.md

## 8. 技术实现

- 纯HTML/CSS/JS，无框架依赖
- 使用CSS Grid和Flexbox布局
- 响应式设计支持多种屏幕尺寸
- 统一的视觉风格（Ant Design风格）
